# Cookbench v0.4.3

An unsigned reliability preview, published from a local build without GitHub
Actions because the maintainer's CI quota is exhausted.

## Changes

- Recognize native Grok Build parent sessions using `info.id`, bounded metadata
  reads, and standard plus `_x.ai/session/update` ACP envelopes. Parse native
  completion events and Unix-second timestamps; filter internal subagents.
- Prevent false exact Grok returns when identities are ambiguous, multiple
  sessions share a process, or process inspection is incomplete. Application
  and project fallbacks now describe the requested destination accurately.
- Fit dense Full Bars to monitor work areas, preserve Full/Minimal transitions,
  and queue monitor refreshes across asynchronous window interactions.
- Retain main's Windows/Linux fixes and fix macOS build compatibility.
- Clarify protocol capability versus actual host evidence in both READMEs.
  Document safe, autonomous host-specific adaptation for tools such as Cline
  and ZCode, while preserving observation-only and privacy boundaries.

## Downloads

This release includes source and `Cookbench-0.4.3-macos-arm64.app.zip`, built on
Apple silicon, plus SHA-256 checksums, an artifact manifest, and a first-party
SPDX artifact inventory. The App ZIP is not signed/notarized for distribution.
It is not a universal/Intel build.

Windows and Linux installers are not included in this local publication.
Build the `v0.4.3` source on those platforms. The existing one-command installer
examples remain pinned to v0.4.2, the previous complete binary release; they do
not install v0.4.3. No old binaries have been relabeled as this version.

## Verification and Known Limits

- Local macOS verification covers formatting, Clippy, Rust workspace tests and
  build, TypeScript, 186 Vitest tests, three GNOME protocol tests, 24 Playwright
  flows, production isolation, and the source-package audit.
- The maintainer reports completing native Windows and Linux testing in place
  of CI. OS/build details and machine-readable logs were not supplied to this
  publishing session; no GitHub CI pass is claimed for this release.
- Two live Grok Build parent sessions were detected on macOS. Both return
  actions requested the host application, not an exact conversation. One
  process holding several session files is insufficient identity evidence.
- Custom `GROK_HOME` discovery works, but exact terminal proof currently requires
  the standard `.grok/sessions` layout and otherwise falls back.
- An existing native watcher startup test can exceed its five-second deadline
  at high Rust test concurrency. The full local gate passes with
  `RUST_TEST_THREADS=1`; this timing risk is not claimed fixed.
- The dynamic macOS status-Stove feature remains suspended. This release does
  not change that safety decision.

See [the scoped macOS verification record](https://github.com/finitein/cookbench/blob/v0.4.3/docs/verification/macos-main-2026-09-08.md).
